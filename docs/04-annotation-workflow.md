# 04 · 标注工作流（Annotation Workflow）

## 1. 目标

用**最小点击量**产出**可训练、可复核、可审计**的标注：模型先给草稿（预标注），人工只做纠正；复核只抽检必要比例；所有改动可回溯。

## 2. 角色与职责

| 角色 | 职责 | 产出 |
|---|---|---|
| 巡检员 | 上传影像、补录路段/位置 | `batches` / `images` |
| 标注员 | 修正预标注、补充漏标、标掩膜 | `annotations` |
| 复核员 | 抽检、打回、定义一致性阈值 | `reviews` |
| 算法 | 选样冻结、训练、看指标、决定晋级 | `dataset_versions` / `model_versions` |

## 3. 标准作业流程（SOP）

```
① 导入(巡检员)           ② 预标注(系统)         ③ 人工标注(标注员)        ④ 复核(复核员)        ⑤ 冻结+训练(算法)
上传照片/视频/航拍  →  现役模型出候选框/掩膜  →  修正+补漏（快捷键）  →  抽检 20% 或低置信度  →  冻结 ds-x → 训练 → 门禁
     │                      │ 失败自动降级            │ 可"复制上一帧"        │ 打回→回到③          │
     └─ 去重/GPS/切片        └─ source=model          └─ source=model_edited  └─ reviews 表           └─ audit_log
```

## 4. 标注台交互规范（详规见 07-ui-spec）

### 4.1 快捷键（默认，可配置）

| 键 | 动作 |
|---|---|
| `1`–`9` | 选择第 N 类（顺序 = 标注台类别条） |
| 拖拽 / `B` | 新建矩形框 |
| `M` | 切换掩膜模式（裂缝类可用，点/框提示生成） |
| `Delete` / `Backspace` | 删除选中标注 |
| `D` / `A` | 下一张 / 上一张 |
| `C` | 复制上一张（或同路段上一帧）的标签 |
| `Q` / `E` | 缩小 / 放大；`空格+拖拽` 平移 |
| `Z` | 一键载入预标注（若该图有 `source=model` 的候选） |
| `S` / `W` | 保存并下一张 |
| `Esc` | 取消当前绘制 / 取消选中 |

### 4.2 判读规则（写进标注手册，供标注员培训）

| 类别 | 判定要点 | 易混/边界 |
|---|---|---|
| 横向裂缝 `transverse_crack` | 走向近似垂直于行车方向 | 与横向接缝（伸缩缝）区分：缝宽均匀、笔直、贯穿整幅路面的多为接缝，标 `difficult=1` 或跳过 |
| 纵向裂缝 `longitudinal_crack` | 走向近似平行于行车方向 | 车辙边缘的顺直细线若为轮迹痕迹（非破损）不标 |
| 坑洞 `pothole` | 有深度、边缘破损、轮廓不规则 | 与井盖下陷、修补块区分；修补块若明显破损可标坑洞并注明 |
| 垃圾 `garbage` | 路面上的固体废弃物（纸箱、塑料袋、建筑渣土等） | 与落叶/水渍区分；积水不标（未来类别） |

**框的松紧**：框应贴合目标外接矩形，缝隙不超过目标宽度的 10%；裂缝类过长时可分段（每段 ≤ 300px）以提升检测稳定性，训练时不算错误。

### 4.3 掩膜（可选增强，仅裂缝类）

- 触发：选中框后按 `M` → SAM 以框为提示生成掩膜 → 人工用橡皮/画笔修正。
- 存储：`annotations.kind='mask'` + `mask_path`（PNG）。
- 用途：派生指标（裂缝长度/平均宽度/面积），不参与检测模型首版训练；后续可作分割任务标签。
- 不强制：无掩膜不影响 `approved` 状态。

## 5. 模型辅助标注

### 5.1 预标注管线

```
任务队列(pending) ──批选──▶ prelabel run
   ├─ 检测：现役 YOLO11（可指定 model_version）→ 候选框（conf ≥ 阈值，默认 0.25）
   ├─ 切片：大图/航拍按 tile(1024, overlap 0.2) 推理 → SAHI 合并（NMS IoU 0.5）
   ├─ 零样本(可选)：垃圾类用开放词表模型补充候选
   └─ 掩膜(可选)：对高置信裂缝框调用 SAM 生成候选掩膜
   ▼
annotations(source='model', score=conf, model_version_id=...)  ──▶ 标注台可选载入
```

### 5.2 预标注质量约束（避免"机器教坏人"）

- 预标注**只作为候选**：默认不进入 `annotated` 状态，必须人工确认（按 `Z` 载入后仍需 `S` 提交）。
- 低置信度（0.25–0.45）候选默认**灰色半透明**显示，需人工判断。
- 每轮预标注记录 `runs` 与 `model_version_id`，用于事后分析"模型错误被复制进训练集"的风险（模型-人工一致率统计）。
- 引入"预标注采纳率"指标：`source='model_edited'` 且框变化 < 10% 视为采纳，用于衡量模型质量趋势。

### 5.3 主动学习闭环

```
训练 → 评估 → 生产模型
   │                 │
   └─ 对未标注池打分 ◀┘
         │
         ├─ 不确定性采样：分类置信度接近阈值 / 多类得分相近
         ├─ 多样性采样：按 pHash 聚类，每簇取 1 张
         └─ 错误驱动采样：混淆矩阵中高混淆类别的样本优先
         ▼
   生成"优先标注队列"（tasks.priority 提升）
```

## 6. 复核与质量管理

| 机制 | 规则 |
|---|---|
| 抽检比例 | 默认 20%（可配）；新标注员前 50 张 100% 全检 |
| 优先复核 | 预标注来源占比高、类别为垃圾/坑洞（更易错）、框面积异常（过大/过小）的优先 |
| 打回原因 | `missing`（漏标）、`wrong_class`（错类）、`loose_box`/`tight_box`（框松紧）、`mask_bad`、`other`；打回必填原因 |
| 一致性度量 | 同图双标：类别一致率、框 IoU 均值、Cohen's Kappa（按类别计算）；阈值 Kappa < 0.7 触发标注规范复训 |
| 冻结前门禁 | 数据集冻结要求：`approved` 比例 ≥ 95%、必填类别各 ≥ 200 框、无 `rejected` 未处理任务 |

## 7. 审计与留痕

- 标注每次提交写 `audit_log`（`before_json`/`after_json` 只存差异字段），保留删除（`deleted_at`）而非物理删除。
- 任何"批量操作"（复制上一帧、批量载入预标注、批量打回）都记录为一个审计条目，含样本 ID 列表。
- 审计日志只增不改；备份时与 `app.db` 一起打包。

## 8. 标注效率基线（用于容量规划）

| 操作 | 目标耗时 | 说明 |
|---|---|---|
| 一张普通照片（3 框，预标注可用） | ≤ 20s | 主要是确认与微调 |
| 一张垃圾/坑洞（需人工判读） | ≤ 40s | 含类别判定 |
| 裂缝掩膜（若做） | ≤ 60s/框 | SAM 提示 + 修正 |

按 20s/张估算，**5,000 张 ≈ 28 人时**；其中预标注可用率若达 70%，可压到 ~20 人时。

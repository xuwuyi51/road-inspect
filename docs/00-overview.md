# 00 · 项目总览（Overview）

> 项目代号：`road-inspect` ｜ 文档版本：v1.0 ｜ 状态：架构设计（未实现）

## 1. 项目是什么

一款**轻量级道路灾害巡查程序**：对道路影像自动识别四类灾害——
**横向裂缝、纵向裂缝、坑洞、垃圾**（类别可扩展）——并提供
**人工标注**与**模型辅助标注**能力，形成"采集 → 标注 → 训练 → 推理 → 复核"的闭环。

程序有两种运行形态，共用同一套模型与数据契约：

| 形态 | 载体 | 用途 |
|---|---|---|
| **工作站形态（首版）** | 本机 Web 应用（FastAPI + 浏览器标注台） | 数据集管理、标注/复核、训练与评估、模型导出 |
| **边缘形态（后续）** | 单文件 CLI + ONNX/TensorRT 模型 | 巡检车/随身设备离线推理，产出结构化结果 |

## 2. 为什么这么设计

1. **轻量优先**：不引入 CVAT / Label Studio 这类重型标注平台，不依赖 Kubernetes、对象存储、消息队列；单机 SQLite + 文件目录即可跑通全流程，常驻内存目标 < 300MB。
2. **闭环优先**：标注工具与训练/推理在同一程序内，模型辅助标注（预标注）与主动学习直接复用同一份类别定义与数据表，避免"标注在 A 工具、训练在 B 脚本、格式靠手工转换"的常见断裂。
3. **边缘可用**：所有模型都能导出 ONNX，边缘端零 Python-UI 依赖；推理后处理与工作站训练时完全一致（同一份后处理代码）。
4. **可扩展**：类别不是硬编码常量，而是数据库中的注册表 + YAML 分类法；新增类别（如网裂、井盖、积水）只需注册 + 补数据 + 重训。

## 3. 范围

### 3.1 在范围内

- 三类采集源的统一导入：**手机/相机照片（含 EXIF）**、**行车记录仪视频（抽帧 + GPS 对齐）**、**无人机航拍影像（大图切片）**；
- 数据去重（SHA256 + 感知哈希）、GPS/时间戳入库；
- 标注台：矩形框标注、类别热键、模型预标注一键载入、掩膜可选校正、复核与打回；
- 模型辅助标注：检测框预标注（YOLO11）、裂缝掩膜（SAM 提示式分割）、垃圾类零样本预标注；
- 数据集冻结与版本化（可复现训练）；
- 小样本训练闭环（3–5k 张起步）、分类别评估、权重门禁；
- 模型导出（ONNX）与边缘离线推理 CLI；
- 统计报表（病害数量/类型分布/位置导出）。

### 3.2 不在范围内（本期）

- GIS 地图渲染、路网拓扑与工单派单系统；
- 多用户账号体系与权限（首版单用户）；
- 移动端 App（用手机浏览器上传即可）；
- 病害严重程度自动评级（预留字段，后续版本）；
- 云端多机训练与分布式推理。

## 4. 术语表

| 术语 | 含义 |
|---|---|
| 灾害类别（class） | 四类：`transverse_crack` 横向裂缝、`longitudinal_crack` 纵向裂缝、`pothole` 坑洞、`garbage` 垃圾 |
| CRDDC 四类 | 公开数据集通行命名：D00 纵向裂缝、D10 横向裂缝、D20 网裂、D40 坑洞 |
| bbox | 矩形检测框（normalized `cx cy w h` 或像素 `x1 y1 x2 y2`） |
| 掩膜（mask） | 像素级分割结果，用于裂缝宽度/面积等派生指标；本项目为可选增强 |
| 预标注（pre-label） | 模型先给出候选框/掩膜，人工在此基础上修正 |
| 切片推理（SAHI） | 把大图切成有重叠的 tile 分别推理，再合并去重，提升细裂缝/小目标召回 |
| 数据集冻结（freeze） | 把当次训练用到的图片、标注、类别、划分固化为不可变版本，并生成哈希清单 |
| 门禁（gate） | 新权重必须在冻结验证集上不低于现役权重，才允许升级为生产模型 |
| 任务（task） | 一张图片在当前流程中的处理单元，带状态机与负责人 |

## 6. 约束（来自本机实测环境）

| 约束 | 数值 | 设计影响 |
|---|---|---|
| GPU | RTX 5060 Ti，15.5GB | 可训练 YOLO11n/s（640, batch 8–16），可跑 SAM 推理 |
| 内存 | 15GB（可用 ~13GB） | 训练 dataloader workers ≤ 4；标注台常驻 < 300MB |
| 磁盘 | **剩 27GB，无第二块盘** | 首版只取 3–5k 张小样本；文档给出外接盘/NAS 接入方案 |
| Python | 3.10（DiffSynth venv）/ 3.12（系统） | 项目自建独立 venv，不污染现有环境 |
| 现成依赖 | torch 2.13+cu130、onnxruntime 1.28、PyYAML、ffmpeg | 需新增 ultralytics、opencv、fastapi 等 |
| 网络 | GitHub raw 不稳、npm/HF 镜像可用 | 数据与模型下载走 HF 镜像/分片，提供离线导入路径 |

# ADR-0007：主动学习与模型门禁

- **状态**：已接受（2026-09）
- **相关**：04-annotation-workflow、05-model-plan、09-roadmap

## 背景

小样本场景下，标注预算是最稀缺资源：**标注什么**比**标多少**更重要。同时，模型迭代容易"越训越差"（标注噪声累积、类别不均衡、过拟合小验证集），需要客观的准入机制。

## 决策

### 1. 主动学习：三类采样策略组合选样

| 策略 | 权重 | 规则 |
|---|---|---|
| 不确定性 | 50% | 最高类置信度落在 [0.25, 0.45]，或 top1−top2 < 0.1 |
| 错误驱动 | 30% | 混淆矩阵中高混淆类别对（如横裂↔纵裂、坑洞↔修补块）的样本优先 |
| 多样性 | 20% | pHash 聚类，每簇取 1 张，避免同路段冗余 |

选样结果体现为 `tasks.priority` 提升，通过 `GET /api/tasks?strategy=low_conf` 暴露给标注台。

### 2. 模型门禁：晋级必须可比较

- 新权重只能在**同一冻结测试集**上与现役 `production` 权重比较；
- 通过条件：总体 mAP50 不低于基线（容差 ±0.005），且**任一类不得下降超过 0.02**（防止"总体达标、某类塌陷"）；
- 未通过 → 保持 `candidate`，`gate_json` 记录 baseline、delta、失败原因；禁止进入 `production`（API 返回 `gate_failed` 409）；
- 连续两次门禁不通过 → 触发标注规范复查（Kappa、打回率、类别定义）。

### 3. 预标注采纳率作为模型质量旁证

记录 `source=model_edited` 且框变化 <10% 的比例（采纳率）与人工新增/删除数量；采纳率下降往往先于 mAP 下降出现，作为预警信号。

## 理由

- 不确定性采样在检测任务上性价比最高；多样性采样防止"同一路段重复标"；
- 门禁把"感觉更好了"变成可验证的准入条件，避免生产模型被劣化权重替换；
- 采纳率是无需额外标注的在线指标，成本极低。

## 后果

- 正面：标注预算投向信息量最大的样本；模型演进可对比、可回滚（保留 `production` 与被替换权重）。
- 负面：需要维护冻结测试集（不能用于训练）；主动学习引入额外的推理与聚类开销（可离线批处理，成本可控）。

## 替代方案

| 方案 | 未采用原因 |
|---|---|
| 随机采样标注 | 效率低，小样本下浪费预算 |
| 仅用 mAP 决定上线 | 无法防类别塌陷，也缺少"回滚依据" |
| 用未冻结的"最新数据"评估 | 不可复现，指标不可比 |

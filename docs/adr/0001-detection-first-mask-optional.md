# ADR-0001：检测优先，裂缝掩膜作为可选增强

- **状态**：已接受（2026-09）
- **相关**：04-annotation-workflow、05-model-plan、07-ui-spec

## 背景

四类目标中，横向/纵向裂缝是**细长结构**：外接矩形会包含大量背景，框的"信息密度"低；坑洞与垃圾更接近常规物体，框足够表达。直觉上裂缝应该做分割（掩膜），但分割标注成本高（约为框标注的 3–5 倍工时），且小样本下分割模型更难收敛。

用户已明确选择"检测框为主 + 裂缝可选分割掩膜"。

## 决策

1. 训练与推理主任务 = **目标检测（bbox）**；四类统一用框表达。
2. 裂缝类**可选**增加掩膜：由 SAM 以框为提示生成候选掩膜，人工修正后入库（`annotations.kind='mask'`）。
3. 掩膜**不参与首版检测训练**，只用于派生指标（裂缝长度/平均宽度/面积）与后续分割任务。
4. 无掩膜不影响任务 `approved`；标注台不强制掩膜流程。

## 理由

- 小样本（3–5k）下，检测的标注量与收敛难度都显著低于分割；
- 框坐标归一化后可跨分辨率复用，便于切片与合并；
- 掩膜用 SAM 提示式生成可把单框成本从分钟级降到 10–60 秒；
- 派生宽度指标对养护决策（是否灌缝/铣刨）已足够，不必先做全量分割。

## 后果

- 正面：M1/M2 可快速闭环；标注成本可控；类别扩展只需框。
- 负面：裂缝宽度/面积精度依赖掩膜覆盖率；后续若做分割需要迁移数据标注（`kind` 字段已预留，无需改表）。

## 替代方案

| 方案 | 未采用原因 |
|---|---|
| 全量多边形分割 | 标注成本过高，小样本下收益不明确 |
| 只用框，不做掩膜 | 放弃裂缝量化能力，养护价值打折 |
| 用"骨架线"（keypoint/线标注） | 工具链支持差、格式互通困难 |

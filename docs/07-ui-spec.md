# 07 · 界面规范（UI Spec）

## 1. 信息架构

```
road-inspect（单页应用，左侧导航）
├── 导入台     /import        上传/登记目录、抽帧与切片参数、去重报告
├── 标注台     /annotate      任务队列 + 画布标注（核心页面）
├── 复核台     /review        抽检队列、通过/打回、一致性统计入口
├── 数据集     /datasets      选样、冻结、导出（YOLO/COCO/LabelMe）
├── 训练       /runs          训练/评估任务、实时日志、指标
├── 模型       /models        模型注册表、门禁状态、晋级、导出边缘包
├── 统计       /stats         类别分布、批次进度、标注效率、明细导出
└── 设置       /settings      类别管理、路径与阈值、预标注开关、快捷键
```

## 2. 全局规范

| 项 | 规范 |
|---|---|
| 语言 | 简体中文（预留 i18n key，不做多语言切换） |
| 配色 | 类别颜色从 `/api/classes.color` 读取（单一来源）；界面用中性灰阶 + 单一强调色（#2563eb） |
| 字号 | 13px 正文 / 12px 辅助 / 15px 标题；表格紧凑行高 32px |
| 快捷键 | 全局 `?` 打开快捷键面板；标注台见 §3.3 |
| 加载 | 列表用骨架屏；长任务用进度条 + 可展开日志；超过 3s 显示"仍在处理" |
| 错误 | 顶部 toast（3s）+ 可展开详情（错误码、trace_id、建议动作） |
| 空态 | 每页给出"下一步做什么"的引导（如标注台空队列 → 去导入台/调整筛选） |
| 无障碍 | 全部操作可用键盘完成；对比度 ≥ 4.5:1；颜色不作为唯一信息载体（类别同时显示名称） |
| 性能 | 列表虚拟滚动（>200 行）；缩略图懒加载（IntersectionObserver）；大图按块加载 |

## 3. 标注台（核心页面）

### 3.1 布局

```
┌───────────────────────────────────────────────────────────────────────────┐
│ 顶栏：任务 12/50 ｜ 批次 2026-09-12 巡检 ｜ 预标注: 已载入(3) ｜ 保存状态   │
├───────────────┬───────────────────────────────────────┬───────────────────┤
│ 任务队列(左)   │            画布(中)                    │ 标注列表(右)      │
│ · 缩略图+状态  │  ┌───────────────────────────────┐    │ ▸ 横裂 0.87 model │
│ · 过滤: 状态/类 │  │  影像 + 标注框 + 掩膜叠加层    │    │ ▸ 坑洞 0.71 model │
│ · 快捷键提示   │  │  缩放/平移/亮度对比度           │    │ ▸ 垃圾 人工        │
│               │  └───────────────────────────────┘    │ 类别条(1-5)       │
│               │  工具条：选择/框/掩膜/删除/撤销         │ 备注/困难标记      │
├───────────────┴───────────────────────────────────────┴───────────────────┤
│ 底部：图 12/50 ｜ 缩放 100% ｜ 坐标 x,y ｜ 快捷键：数字选类 · Z 载预标注 · S 保存 │
└───────────────────────────────────────────────────────────────────────────┘
```

### 3.2 元素与行为

| 元素 | 行为 |
|---|---|
| 画布 | 影像 + 三层叠加（人工框实线 / 模型候选虚线半透明 / 掩膜半透明填充）；支持滚轮缩放（以光标为锚点）、空格拖拽平移 |
| 类别条 | 数字键切换当前类；显示颜色点 + 中文名；来自 `/api/classes`（active=1） |
| 候选面板 | 列出该图的 `source=model` 标注，逐条"采纳/忽略"；`Z` 全部采纳并进入可编辑状态 |
| 框操作 | 拖拽移动、8 向手柄缩放；框过小（<8px）提示并自动扩大；重叠框高亮 |
| 掩膜工具 | 裂缝类专用：选中框后 `M` → SAM 生成 → 画笔/橡皮（大小可调）→ 确认 |
| 复制上一帧 | `C`：复制上一张（或同路段最近一张）的标签到当前图，作为编辑起点；记录审计 |
| 亮度/对比度 | 滑块（仅显示层，不改原图）；夜间/逆光影像必备 |
| 保存 | 自动草稿（每 10s 或每次改动后本地缓存）+ 显式 `S` 提交；提交冲突提示"任务已被他人领取" |
| 提交状态 | 顶栏显示"未保存/已保存/提交中/已提交"，提交后自动切下一张 |

### 3.3 快捷键（详见 04-annotation-workflow §4.1）

`1-9` 选类 ｜ `B` 框 ｜ `M` 掩膜 ｜ `Delete` 删除 ｜ `D/A` 下一张/上一张 ｜ `C` 复制上一帧 ｜ `Q/E` 缩放 ｜ `Z` 载入预标注 ｜ `S` 保存并下一张 ｜ `Esc` 取消 ｜ `?` 快捷键面板 ｜ `Ctrl+Z` 撤销（本地 20 步）

### 3.4 状态与异常

| 情况 | 表现 |
|---|---|
| 预标注失败 | 顶部黄色提示"该图预标注失败（原因）"，进入纯人工模式 |
| 图片加载失败 | 画布占位 + "重新加载"，并提供"标记为损坏"（`status=skipped`） |
| 任务被抢占 | 只读遮罩 + "任务已被 {assignee} 领取"，提供"取新任务" |
| 网络中断 | 离线草稿继续可编辑，恢复后提示"有 3 处本地改动待提交" |

## 4. 复核台

- 左：复核队列（默认 `strategy=low_conf`，可切随机抽检 20%）；显示预标注占比、类别、置信度。
- 中：**对比视图**——左"提交时的标注"、右"复核中的修改"（叠加差异高亮：新增绿框、删除红叉、类别变更黄边）。
- 右：判读要点卡片（四类判定规则摘要，来自 04 文档）+ 打回原因单选（六类）+ 备注。
- 底部：`通过`（`Enter`）/`打回`（`R`）并自动下一张；顶部显示今日复核量与打回率。
- 一致性：页面右上"一致性报告"入口，展示类别一致率、框 IoU 均值、Kappa。

## 5. 其他页面要点

### 5.1 导入台
- 拖拽区 + "服务器目录"输入（校验白名单）；参数折叠面板（抽帧 fps、去重阈值、切片开关）。
- 导入完成显示报告：新增 / SHA 重复 / 近似重复 / 跳过类型 / 失败，失败项可导出 CSV。
- 大视频显示抽帧进度与预览缩略图条。

### 5.2 数据集
- 过滤器表单（类别、批次、时间、复核状态）→ "预览选样"显示各类计数与划分预览（train/val/test 饼图）。
- 冻结按钮二次确认（提示"冻结后不可修改，将生成不可变版本"）；冻结后显示 `manifest_hash`（可复制）。
- 导出：三格式按钮 + 产物路径；导出包大小提示。

### 5.3 训练
- 表单：数据集（仅 frozen 可选）、模型规格（yolo11n/s）、imgsz、epochs、batch、seed、`flipud`（锁定为 false 并注明原因）、可选 `resume_from`。
- 运行中：日志尾部（自动滚动）、进度（epoch/总）、资源占用（GPU 显存、显存峰值）。
- 完成：分类别指标表 + 混淆矩阵缩略图 + "对比现役"按钮（显示门禁 delta）。

### 5.4 模型
- 列表：名称/版本/任务/状态/训练集/关键指标/门禁结论。
- 操作：晋级（candidate→validated→production，门禁失败时按钮禁用并显示原因）、导出边缘包（显示目标路径与文件清单）。

### 5.5 统计
- 卡片：总图片数、已标注、待复核、各类别框数、平均标注耗时。
- 图表：类别分布柱状、按批次堆叠、按日期趋势（近 30 天）。
- 导出：CSV/JSON（含经纬度、路段号、置信度），供 GIS/报表使用。

### 5.6 设置
- 类别管理（增改颜色/顺序/启用；禁用而非删除）、预标注开关与阈值默认值、路径与磁盘占用、快捷键自定义、`allowed_roots` 白名单。

## 6. 前端技术约定

| 项 | 约定 |
|---|---|
| 技术栈 | Vite + React 18 + Konva（画布）；TypeScript |
| 状态 | 轻量 store（Zustand 或 React Query 缓存服务端状态）；不做全局大对象 |
| API 客户端 | 由 `openapi.yaml` 生成类型与请求函数，避免手写不一致 |
| 目录 | `web/src/{pages,components,canvas,api,store}`；标注画布独立包 `canvas/` 便于测试 |
| 构建产物 | `web/dist` 由服务端静态托管（单端口）；开发期 `vite dev` 代理 `/api` |
| 测试 | 画布几何（框缩放/坐标换算）用单测；标注流程用 Playwright 端到端（导出→标注→提交→复核） |
| 体积目标 | 首屏 JS gzip < 350KB（Konva 不计入首屏，标注页按需加载） |
